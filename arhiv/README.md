# Архив

**Правило: файлы отсюда не читать при обычной работе.** Не брать их как источник, не искать в них формулировки, не сверяться с ними. Они устарели и противоречат текущему курсу — именно поэтому лежат здесь, а не в рабочих папках.

Читать только если продюсер прямо попросит: «посмотри в архиве», «как было раньше», «почему мы от этого ушли».

Ничего не удалено: всё лежит целиком, история в гите сохранена. Если решение развернётся обратно, файл возвращается на место одной командой.

## `vina-staryy-flagman/` — курс до разворота 11.08

Проект строился вокруг темы **вины** и флагмана **«Я выбираю себя»** (цена 24 990). На созвоне 11.08 Виола сказала, что эта аудитория бедная (максимум 50–60 €), и флагман пересобран под платёжеспособного эмпата — «Любовь и деньги». Разбор решения — `produkt/sozvon-viola-11.08-itogi.md`.

| Файл | Что это было |
|---|---|
| `ofer-ya-vybirayu-sebya.md` | Оффер отменённого флагмана: скелет, банк формулировок, цена 24 990 |
| `ca-ya-vybirayu-sebya.md` | Портрет ЦА под этот флагман (углы С1 + С5, внешнее давление) |
| `ca-analiz-v1.1.md` | Анализ ЦА v1.1 — выдача внешнего ИИ, тема вины |
| `ca-framework.md` | Каркас «осведомлённость × ценность» по старой ЦА, собран из трёх файлов выше |
| `anketa-predzapisi.md` | Анкета предзаписи под разбор про вину |

**Важно:** тема вины **не умерла целиком** — она осталась дешёвым входом воронки. Живые файлы по ней в рабочих папках: `baza/kanon-viny.md`, `analitika/ca-lidmagnit.md`, `analitika/ca-voc.md`.

## `lyubov-i-dengi/` — флагман до пересборки 13.08

Продукт назывался **«Любовь и деньги»**, месяц, шесть лекций, тарифы 19 900 / 29 900 / 39 900. 13.08 продюсер снял название и пересобрал конструкцию вокруг внимания Виолы: шесть недель по сферам, ответы голосом дважды в неделю, тарифы 9 900 / 34 900 / 149 000. Действующий продукт — `produkt/praktikum-dlya-empatov.md`, обоснование — `produkt/gipoteza-produkt-vokrug-lichnosti.md`.

| Файл | Что это было |
|---|---|
| `prezentatsiya-lyubov-i-dengi.md` | Прежний источник правды: оффер, программа, тарифы, правки Виолы 12.08. **Канон тарифной сетки и правки по голосу перенесены** в новый файл |
| `odnostranichnik-sozvon-lyubov-i-dengi.md` | Клиентская часть сжато, для созвона |
| `programma-lyubov-i-dengi-v1.md` | Методическая начинка шести шагов |
| `blok-do-posle-prorabotka.md` | Черновики блока «до и после» к прежнему офферу |
| `Любовь-и-деньги-презентация.docx` | Собранный docx для команды |

⚠️ **Не выбрасывать при разборе:** методическая начинка шагов и блок «до/после» могут пригодиться, когда будем расписывать материалы по неделям.
