# Анкета предзаписи — Виола Маро

Готова к сборке формы (Google Forms / Тильда / Марквиз). Копия в Google Drive: Google-документ «Виола — Анкета предзаписи».

**Вступление (первый экран):** Пара минут. Это поможет собрать разбор под ваши ситуации, а не «вообще про вину». Ответы анонимны, контакт — по желанию в конце.

**Контакт (последний экран, по желанию):** Telegram или имя — чтобы прислать приглашение.

**После отправки:** Спасибо. Если оставили контакт — пришлём приглашение первыми.

**Заметки по сборке:**
- Обязательные: В1, В2, В3, В5, В7. Остальное по желанию, чтобы не терять заполнивших.
- Один экран — один вопрос, если конструктор умеет.
- Красные линии в формулировках: без «токсичных», «нарциссов», «эмпатов», без обещаний результата.
- Специально не спрашиваем «готовы заплатить 1990» — ложный сигнал; мерим важность.
- Каждый ответ кодируется в сегмент/ось. Когда пойдут ответы — соберём в `skripty/` разборщик долей по углам и барьерам.
