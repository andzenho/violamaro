# Виола Маро — рабочий репозиторий

Запуск линейки онлайн-продуктов психотерапевта Виолы Маро.
Здесь живут все смыслы проекта: голос, каноны, продукты, аналитика ЦА и
контент-план. Google-таблицы и Telegram — витрины, **источник правды здесь.**

**Кто что делает:** продюсер — маркетинг, продажи, тексты · Артём — контент и
трафик · Аня — документы и продажи · ассистент (Claude Code) — сборка текстов
и ведение базы.

---

## Что где лежит

| Папка | Что внутри |
|---|---|
| **`baza/`** | Голос Виолы и тематические каноны. **Источник правды по смыслу.** Сюда пишем только проверенное и с меткой источника. |
| **`produkt/`** | Программы, цены, тарифы, лендинги. Флагман — практикум «Прикладная эмпатия». |
| **`analitika/`** | ЦА: портреты, кастдэвы, банк дословных фраз, цифры. |
| **`kontent/kp/`** | **Контент-план.** Папка на вкладку, файл на пост по дате. Синхронизируется в Google-таблицу. |
| **`korpus/`** | Сырьё: неотредактированные транскрипты Виолы. Читается, не правится. |
| **`docs/`** | Опубликованные страницы: [тесты на GitHub Pages](https://andzenho.github.io/violamaro/). |
| **`skripty/`** | Служебные скрипты. Что и как запускать — [`skripty/README.md`](skripty/README.md). |
| **`arhiv/`** | Устаревшее и противоречащее курсу. **Не читать при обычной работе.** |

Полный индекс с весом каждого файла — **[`karta.md`](karta.md)**.
История решений «что и почему поменяли» — **[`baza/zhurnal-resheniy.md`](baza/zhurnal-resheniy.md)**.

## Правила работы

- **Коммит и пуш — только по прямому «да» продюсера.** Ассистент сам не коммитит.
- Все машины работают с веткой `main`. Ветка под задачу — одна, от свежего `main`.
- Тексты от лица Виолы пишутся только после чтения `baza/golos-viola.md`, не по памяти.
- Кодекс честности: никаких считываемых продающих манипуляций. Тест «в лицо» —
  можем объяснить приём аудитории и не покраснеть, значит оставляем.

Полные правила для ассистента — [`CLAUDE.md`](CLAUDE.md) и `.claude/rules/`.

## Для ассистента (Claude Code)

Контекст собран по принципу «грузим только нужное»:

- **`CLAUDE.md`** (~1,9 тыс. токенов) — грузится в каждой сессии. Только то, что
  нужно всегда.
- **`.claude/rules/*.md`** — правила по разделам. Подгружаются сами, когда
  ассистент открывает файл в соответствующей папке.
- **`karta.md`** — индекс репозитория, читается по требованию вместо угадывания.
- **`.claude/hooks/strazh_chteniya.py`** — не даёт прочитать целиком файл
  тяжелее 10 тыс. токенов: длинный контекст измеримо снижает точность.
- **`.claude/commands/`** — команды: `/post`, `/den`, `/dyrki`, `/proverka`,
  `/sait`, `/transkript`.

После изменения структуры репозитория:

```bash
python3 skripty/karta.py                    # пересобрать индекс
python3 skripty/oglavlenie.py --vse         # обновить оглавления тяжёлых файлов
```
