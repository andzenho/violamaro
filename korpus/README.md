# korpus/ — сырьё

Сюда кладём только **исходники**: неотредактированные транскрипты Виолы и ничего больше.

- Только сырая речь, дословные записи.
- Ничего не переписывать, не редактировать, не чистить.
- Имена файлов с номером: `01-lidmagnit.txt`, `02-otvety.txt`, дальше по порядку.

Корпус — сырьё для базы. Переработка идёт в одну сторону: korpus → baza, никогда наоборот.

## Переносы строк — обязательный шаг приёмки

Новый транскрипт часто приходит одним абзацем на весь файл. Текст от этого не
страдает, а работа — сильно: `grep` возвращает «строку с совпадением», то есть
весь файл целиком, и чтение кусками не работает вовсе. Один поиск по такому
файлу стоил ровно столько же, сколько прочитать его весь: «чувство вины» по
`02-otvety.txt` — 12 671 токен при размере файла 12 672. После переносов — 2 221.

Поэтому сразу после того, как файл лёг в `korpus/`:

    python3 skripty/perenos.py korpus/<файл>            # посмотреть
    python3 skripty/perenos.py korpus/<файл> --primenit # расставить переносы

Это **не редактирование**: скрипт трогает только пробельные символы и сам
сверяет, что текст совпал символ в символ, иначе не пишет. Правило «ничего не
переписывать, не чистить» в силе.

## Большие файлы читать кусками

У методичек внутри есть разметка страниц. Оглавление с номерами строк:

    python3 skripty/karta_korpusa.py korpus/06-metodichka-empatiya-modul2-pole.txt
    python3 skripty/karta_korpusa.py korpus/*.txt --iskat поле

Дальше читаем найденный диапазон через `offset`/`limit`, а не файл целиком:
методичка — это 80–130 тыс. токенов, дороже всей остальной работы над постом.
