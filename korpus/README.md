# korpus/ — сырьё

Сюда кладём только **исходники**: неотредактированные транскрипты Виолы и ничего больше.

- Только сырая речь, дословные записи.
- Ничего не переписывать, не редактировать, не чистить.
- Имена файлов с номером: `01-lidmagnit.txt`, `02-otvety.txt`, дальше по порядку.

Файлы от `skripty/transkript.py` идут с шапкой-источником (метка, ссылка, дата,
длительность, модель расшифровки) и таймкодами `[MM:SS]` в начале абзацев. Это
разметка происхождения, а не правка речи: она нужна, чтобы цитату в базе можно
было проверить по секунде в исходном видео. Саму речь всё так же не трогаем.

Корпус — сырьё для базы. Переработка идёт в одну сторону: korpus → baza, никогда наоборот.
