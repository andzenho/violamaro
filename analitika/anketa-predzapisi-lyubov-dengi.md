# Предзапись «Любовь и деньги» — Google-форма

12.08.2026 · Открывается кнопкой из результата теста (`produkt/test-empat.html`). Видят её **только эмпат-ранги**, отказам предзапись не показываем.

**Это форма записи, а не анкета.** Задача одна: собрать контакт, чтобы позвать в первый поток. Всё остальное — ранг, проценты, восемь шкал, «где съедает», «что менять первым», «что уже делали», «давно смотрит Виолу» — тест уже собрал и отправил в таблицу. Спрашивать это ещё раз значит терять записавшихся.

## Название и описание

**Название:** Любовь и деньги — предзапись

**Описание:**
> Программа Виолы для тех, кто чувствует людей глубже других. Старт осенью.
>
> Оставьте контакты — позовём первыми и по самой низкой цене. Плюс сразу открываем закрытый канал Виолы с материалами и подкастами.

**[1] Как вас зовут** · короткий текст · **обязательное**

**[2] Телефон** · короткий текст · **обязательное**

Три поля, двадцать секунд.

## Сборка в Google Forms

1. Создать форму, четыре поля по списку выше.
2. **Настройки:** «Собирать адреса электронной почты» — выключить. «Ограничить до одного ответа» — выключить (иначе форма потребует вход в Google-аккаунт и половина отвалится).
3. **Ответы → связать с таблицей.** Лучше с той же таблицей, где лежат результаты теста, отдельным листом — тогда данные соединяются по коду.
4. **Экран подтверждения:** вставить текст выше со ссылкой на канал.
5. **Получить предзаполненную ссылку:** три точки справа вверху → «Получить заполненную ссылку» → в поле **[4] Код теста** написать слово `КОД` → «Получить ссылку» → скопировать.

**Что прислать мне:** скопированную ссылку целиком. Она выглядит так:

```
https://docs.google.com/forms/d/e/1FAIpQL…/viewform?usp=pp_url&entry.1234567890=КОД
```

Из неё я возьму адрес формы и номер поля — страница будет подставлять туда настоящий код каждого человека.

## Код теста — зачем он здесь

Формат: `id-ранг-процент`, например `284719503-donor-91`. Страница подставляет его сама.

По нему контакт из формы соединяется со строкой в таблице теста. Без кода у вас список телефонов без лиц; с кодом — видно, кто именно записался, какой у него тип и что он отвечал. Это же даёт главную цифру запуска: **какие ранги доходят до записи**. Если записываются одни Доноры — оффер собран правильно. Если Проснувшиеся — угол смещаем на «куда направить силу».

Если тест открыт в браузере, а не из бота, вместо id будет `web` — связка тогда идёт по телеграму.

## Решения, от которых не отступаем

- **Про цену говорим как о возможности.** «Позовём по самой низкой цене» — да. «Дальше будет дороже» — нет, это связывает руки на будущие продажи. Единственное, чего нельзя при любой формулировке, — продать этой же группе дороже, чем остальным.
- **«Право сказать, что включить» переезжает в канал.** В форме этого вопроса больше нет, но обещание на экране программы осталось. Значит, спросить надо в закрытом канале — первым же постом. Заодно готовый повод для первого касания.
- **Дату старта не называем.** «Осенью» — правда, конкретное число — пока нет.
- **Предзапись видят только эмпат-ранги.** Считывающему и Сочувствующему — канал, не программа.

## Два замечания по цене конверсии

**Телефон — самое дорогое поле формы.** Он же и самый нужный, если продавать будете звонками. Ставим обязательным, как решено, но при первых данных смотрим долю тех, кто открыл форму и не отправил. Если провал большой — телефон делается необязательным одним переключателем, телеграма для приглашения достаточно.

**Замер цены ушёл из формы.** Значит, цена флагмана меряется на созвонах с записавшимися: вилка вслух, «за такое пошли бы? где легко, а где уже дорого». Это надёжнее клика в форме, но требует, чтобы созвоны действительно проводились. Иначе цену ставим наугад.
