# analitika/

Аналитика запуска: воронка, цифры, отчёты скриптов, гипотезы и результаты проверок.
Считаем скриптом, а не на глаз.

## Анализ ЦА
- `ca-data.json` — **источник правды** для живой Google-таблицы «ЦА и продукты».
  Правится как текст (диффается в git), синхронизируется скриптом `skripty/ca_sync.py`.
- `ca-i-produkty.xlsx` — офлайн-снимок той же структуры (8 вкладок).
- `ca-analiz-v1.1.md` — нарратив-запись выдачи с аудитом уверенности.
- `anketa-predzapisi.md` — анкета предзаписи (на потом).

### Синхронизация ЦА в Google-таблицу (repo → таблица, односторонняя)
1. Ключ сервис-аккаунта — тот же, что у `sheets_sync` (переменная `VIOLA_SHEETS_CREDS_JSON`
   или файл `skripty/.google-creds.json`). Нет ключа — попросить продюсера прикрепить.
2. Таблицу ЦА расшарить на email сервис-аккаунта, доступ «Редактор».
3. Зависимости: `python3 -m pip install -r skripty/requirements-sheets.txt`.
4. `python3 skripty/ca_sync.py` (сухой прогон) → показать → `--apply`.

Скрипт создаёт недостающие вкладки и пишет значения. Форматирование, твои
дополнительные колонки и вкладки, которых нет в источнике, он не трогает.
Правки контента делаем в `ca-data.json`, оформление — руками в таблице.
ID таблицы — в `ca-data.json` (`spreadsheet_id_default`) или в `VIOLA_CA_SHEET_ID`.
