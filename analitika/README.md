# analitika/

Аналитика запуска: воронка, цифры, отчёты скриптов, гипотезы. Считаем скриптом, а не на глаз.

## Карта: маркетинговая задача → где брать
- **Крючки словами аудитории** → `ca-voc.md`, `kommentarii-razbor.md`, `tg-kommentarii-razbor.md` (топ по реакциям, дословно).
- **Сетка тем контента** → кластеры вопросов аудитории в `tg-kommentarii-razbor.md`.
- **Весь ЦА в маркетинговом каркасе** (осведомлённость × ценность) → `ca-framework.md`.
- **Продаю конкретный продукт** → бриф: `ca-lidmagnit.md` (вход/лид-магнит), `ca-ya-vybirayu-sebya.md` (флагман).
- **Сегменты / барьеры / запреты формулировок / смыслы** → `ca-data.json` (вкладки) или живая таблица.
- **Что проверено, а что допущение** → аудит уверенности в `ca-analiz-v1.1.md`.
- **Собрать новые комментарии** → `skripty/yt_comments.py` (YouTube), `skripty/tg_comments.py` (Telegram).

Принцип: **один документ на продукт/ступень воронки** (стержень × продукты). Новый продукт → новый `ca-<продукт>.md`, старые не раздуваем.

## Анализ ЦА (файлы)
- `ca-framework.md` — каркас осведомлённости (Шварц) + Value Proposition по сегментам.
- `ca-analiz-v1.1.md` — базовый анализ сегментов С1–С5 + аудит уверенности.
- `ca-lidmagnit.md` — ЦА под вход (лид-магнит): «мне можно / границы / право отказать», С3.
- `ca-ya-vybirayu-sebya.md` — ЦА под флагман «Я выбираю себя» (С1+С5).
- `ca-voc.md` — Voice-of-customer банк (дословные фразы по типам).
- `ca-data.json` — **источник** живой Google-таблицы «ЦА и продукты» (синхр. `skripty/ca_sync.py`); `ca-i-produkty.xlsx` — офлайн-снимок.
- `anketa-predzapisi.md` — анкета предзаписи (инструмент первого замера спроса).

## Разбор комментариев (сырьё → язык и темы, НЕ доли)
- `kommentarii-razbor.md` — YouTube (партии 1–3).
- `tg-kommentarii-razbor.md` — Telegram `violamaro1`.
- `kommentarii/` — сами выгрузки, в git не тянутся (см. `.gitignore`).

## Пайплайн «видео/тема → язык аудитории → позиционирование»
1. **Собрать:** `yt_comments.py <ссылки|--channel>` или `tg_comments.py <экспорт>` (для YouTube нужен `YOUTUBE_API_KEY`).
2. **Разобрать:** `razbor_kommentov.py analitika/kommentarii/<...>/*.jsonl` → топ по лайкам, фигуры, ярлыки, углы, боли.
3. **Сверить с речью Виолы** (`korpus/`, `baza/`) — где язык аудитории совпадает с её словами, там строим заход.
4. **Выводы → в `ca-<продукт>.md`** / `ca-data.json`.

Дисклеймер (всегда): комментарии = язык и темы, не объёмы и не готовность платить. Замер спроса — анкета и событие.

## Синхронизация ЦА в Google-таблицу (repo → таблица, односторонняя)
1. Ключ сервис-аккаунта — тот же, что у `sheets_sync` (`VIOLA_SHEETS_CREDS_JSON` или `skripty/.google-creds.json`).
2. Таблицу ЦА расшарить на email сервис-аккаунта, доступ «Редактор».
3. `python3 -m pip install -r skripty/requirements-sheets.txt`.
4. `python3 skripty/ca_sync.py` (сухой прогон) → `--apply`.

Скрипт создаёт недостающие вкладки и пишет значения; форматирование, доп-колонки и чужие вкладки не трогает. Правки контента — в `ca-data.json`. ID таблицы — `spreadsheet_id_default` в `ca-data.json` или `VIOLA_CA_SHEET_ID`.
