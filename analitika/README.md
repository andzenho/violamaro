# analitika/

Аналитика запуска: ЦА, воронка, цифры, отчёты скриптов. Считаем скриптом, а не на глаз.

## ⭐ Точка входа — `ca.md`

**Единственный свод по аудитории.** Кто это, от чего бежит, к чему тянется, что
держит, что переключает, как продавать, чего мы не знаем. Рамка одна — четыре
вопроса. Пометки: `✓` проверено данными, `~` чтение ассистента.

Свёл в себя `ca-master`, `ca-itog`, `karta-smyslov`, `ca-portret`, `ca-audit`
(03.09). Они пересказывали друг друга, и из-за этого в одном полторы недели
жила отменённая ценовая сетка. Лежат в `arhiv/ca-svedennye/`.

## Источники — свод их не заменяет

По силе сигнала, сверху вниз:

| файл | что это |
|---|---|
| `kastdev-sozvony.md`, `kastdev-03-empat-3potok.md` | созвоны с покупателями. Мотив покупки от первого лица. Сырьё — `kastdev/` |
| `ca-chaty-empatia.md` | 666 сообщений трёх чатов потоков. Поведение платящих |
| `ca-empatia.md`, `ca-klyuchi.md` | разборы чатов «Эмпатия 2.0» и «Ключи» |
| `ca-voc.md` | банк дословных фраз. **Два изолированных раздела**, не смешивать |
| `kommentarii-razbor.md`, `tg-kommentarii-razbor.md` | комментарии YouTube и Telegram. Язык массы, не покупателей |
| `temy-i-triggery.md` | замеры по темам канала: что залетает |
| `ca-data.json` | данные для Google-таблицы «ЦА и продукты» (синхр. `skripty/ca_sync.py`) |

Анкеты: `anketa-pokupateli-empatia.md` (под кастдевы), `anketa-predzapisi-lyubov-dengi.md`.

## Ранг источников

Кастдевы покупателей → чаты потоков → анкеты и тесты → комментарии.
**Виола отдельной осью:** про человека её слово выше всех, про покупку первыми
идут данные. Утверждение идёт в работу с двумя независимыми подтверждениями.
