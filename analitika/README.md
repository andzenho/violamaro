# analitika/

Аналитика запуска: аудитория, цифры, отчёты скриптов, гипотезы. Считаем скриптом, а не на глаз.

## С чего начинать

**Вся команда, простым языком:** `ca-portret.md` — кто наш покупатель, что болит, чего хочет, как с ней разговаривать и кому не продаём. Без цифр и терминов, десять минут. Артёму и Ане — отсюда.

**Кто работает с оффером и продажами:** `ca-master.md` — точка входа. Часть I: кто и с чем приходят. Часть II: почему и когда покупают (JTBD, четыре силы перехода, timeline покупки, уровни осведомлённости, сегменты по работе). Всё остальное — детализация этих двух файлов.

### Сырьё аудитории
`kommentarii-razbor.md` — YouTube (партии 1–7) · `tg-kommentarii-razbor.md` — Telegram `violamaro1` · `kommentarii/` — сами выгрузки, в git не тянутся.

Дисклеймер, всегда: комментарии = **язык и темы, не объёмы и не готовность платить**. Комментируют самые вовлечённые, состав задан контентом.

`ca-data.json` — источник Google-таблицы «ЦА и продукты», синхронизация `skripty/ca_sync.py`. Правки вносим в json, не в таблице: таблица перезаписывается.

## Маркетинговая задача → где брать
- **Крючки словами аудитории** → `ca-voc.md`, `kommentarii-razbor.md`, `tg-kommentarii-razbor.md`.
- **Сетка тем контента** → кластеры вопросов в `tg-kommentarii-razbor.md` + карта внимания канала в `../produkt/transformatsiya-za-dengi.md`.
- **Продаю флагман** → `ca-master.md` + `../produkt/karta-smyslov-i-argumentov.md` (аргумент на каждый смысл + симуляции диалогов).
- **Почему не покупают** → `ca-master.md §2` (тревоги и инерция) + `karta-smyslov-i-argumentov.md`.
- **Что проверено, а что допущение** → `ca-audit.md`.
- **Собрать новые комментарии** → `../skripty/yt_comments.py`, `../skripty/tg_comments.py` → разбор `razbor_kommentov.py`.
- **Карта внимания канала** → `../skripty/yt_stats.py` → разбор в `../produkt/transformatsiya-za-dengi.md`.

Принцип: **один документ на продукт или ступень воронки.** Новый продукт → новый `ca-<продукт>.md`, старые не раздуваем.

## Пайплайн «видео → язык аудитории → позиционирование»
1. **Собрать:** `yt_comments.py <ссылки|--channel>` (нужен `YOUTUBE_API_KEY`) или `tg_comments.py <экспорт>`.
2. **Разобрать:** `razbor_kommentov.py analitika/kommentarii/<...>/*.jsonl`.
3. **Сверить с её речью** (`korpus/`, `baza/`) — где язык аудитории совпадает с её словами, там строим заход.
4. **Выводы** → в `ca-<продукт>.md` и `ca-data.json`.

## Синхронизация ЦА в Google-таблицу (репозиторий → таблица, односторонняя)
1. Ключ сервис-аккаунта — тот же, что у `sheets_sync` (`VIOLA_SHEETS_CREDS_B64` / `VIOLA_SHEETS_CREDS_JSON` / `skripty/.google-creds.json`).
2. Таблицу расшарить на email сервис-аккаунта с ролью «Редактор».
3. `python3 -m pip install -r skripty/requirements-sheets.txt`.
4. `python3 skripty/ca_sync.py` (сухой прогон) → `--apply`.

Скрипт создаёт недостающие вкладки и пишет значения; форматирование, доп-колонки и чужие вкладки не трогает. ID таблицы — `spreadsheet_id_default` в `ca-data.json` или `VIOLA_CA_SHEET_ID`.
