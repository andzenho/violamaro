# analitika/

Аналитика запуска: воронка, цифры, отчёты скриптов, гипотезы и результаты проверок.
Считаем скриптом, а не на глаз.

## Карта: маркетинговая задача → где брать
- **Пишу пост/видео, нужны крючки словами аудитории** → банки крючков в
  `tg-kommentarii-razbor.md` и `kommentarii-razbor.md` (топ по реакциям, дословно).
- **Нужна сетка тем контента** → кластеры вопросов аудитории в `tg-kommentarii-razbor.md`
  (369 вопросов-запросов, провалидированы реакциями). Полный список — `/dyrki` по
  `kommentarii/tg-violamaro1.jsonl`.
- **Продаю конкретный продукт** → бриф под продукт, напр. `ca-ya-vybirayu-sebya.md`
  (кто покупатель, язык продажи, возражения, что проверить до продаж).
- **Нужны сегменты / барьеры / запреты формулировок** → `ca-data.json` (вкладки
  «Сегменты», «Барьеры», «Сообщения») или живая таблица.
- **Что вообще проверено, а что допущение** → аудит уверенности в `ca-analiz-v1.1.md`.
- **Собрать новые комментарии в сырьё** → `skripty/tg_comments.py` (Telegram-экспорт),
  `skripty/yt_comments.py` (YouTube). Кладут в `kommentarii/`.

## Анализ ЦА
- `ca-data.json` — **источник правды** для живой Google-таблицы «ЦА и продукты».
  Правится как текст (диффается в git), синхронизируется скриптом `skripty/ca_sync.py`.
- `ca-i-produkty.xlsx` — офлайн-снимок той же структуры (8 вкладок).
- `ca-analiz-v1.1.md` — нарратив-запись выдачи с аудитом уверенности.
- `ca-ya-vybirayu-sebya.md` — сборка ЦА под продажу флагмана «Я выбираю себя»
  (из речи Виолы + комментарии YouTube и Telegram). Шаблон для брифа под любой продукт.
- `anketa-predzapisi.md` — анкета предзаписи (на потом).

### Разбор комментариев (сырьё аудитории → язык и темы, НЕ доли)
- `tg-kommentarii-razbor.md` — Telegram-канал `violamaro1`, 5178 комментариев.
- `kommentarii-razbor.md` — YouTube Shorts, партия 1.
- `kommentarii/` — сами выгрузки (jsonl/txt), в git не тянутся (см. `.gitignore`).
- Общая оговорка: комментируют самые вовлечённые, состав задан контентом —
  годится как язык крючков и перечень тем, не как замер объёмов (см. `ca-analiz-v1.1.md`).

### Синхронизация ЦА в Google-таблицу (repo → таблица, односторонняя)
1. Ключ сервис-аккаунта — тот же, что у `sheets_sync` (переменная `VIOLA_SHEETS_CREDS_JSON`
   или файл `skripty/.google-creds.json`). Нет ключа — попросить продюсера прикрепить.
2. Таблицу ЦА расшарить на email сервис-аккаунта, доступ «Редактор».
3. Зависимости: `python3 -m pip install -r skripty/requirements-sheets.txt`.
4. `python3 skripty/ca_sync.py` (сухой прогон) → показать → `--apply`.

Скрипт создаёт недостающие вкладки и пишет значения. Форматирование, твои
дополнительные колонки и вкладки, которых нет в источнике, он не трогает.
Правки контента делаем в `ca-data.json`, оформление — руками в таблице.
ID таблицы — в `ca-data.json` (`spreadsheet_id_default`) или в `VIOLA_CA_SHEET_ID`.
