# analitika/

Аналитика запуска: воронка, цифры, отчёты скриптов, гипотезы. Считаем скриптом, а не на глаз.

## Анализ ЦА (карта документов)
Принцип: **один документ на продукт/ступень воронки** (стержень × продукты). Новый продукт → новый `ca-<продукт>.md`, старые не раздуваем.

- `ca-analiz-v1.1.md` — базовый анализ ЦА: сегменты С1–С5, аудит уверенности. Отправная точка.
- `ca-lidmagnit.md` — ЦА под **вход воронки (лид-магнит)**: «мне можно / границы / право отказать», угол С3, крючок на узнавании.
- `ca-ya-vybirayu-sebya.md` — ЦА под **флагман «Я выбираю себя»** (углы С1+С5). *(приезжает из параллельной ветки launch-strategy при слиянии.)*
- `ca-data.json` — источник живой Google-таблицы «ЦА и продукты» (8 вкладок). Синхронизация — `skripty/ca_sync.py`.
- `ca-i-produkty.xlsx` — офлайн-снимок той же структуры.
- `anketa-predzapisi.md` — анкета предзаписи (инструмент первого замера спроса).

## Комментарии аудитории (сырьё языка)
- `kommentarii-razbor.md` — сводные разборы по партиям/темам (язык, фигуры, ярлыки, боли).
- `kommentarii/` — сырые дампы. Верхний уровень gitignored (регенерируются); курируемые подборки (напр. `kommentarii/vina/`) в репозитории.

## Как применять в будущих маркетинговых задачах
Готовый пайплайн **«видео/тема → язык аудитории → позиционирование»**:

1. **Собрать комментарии** (нужен `YOUTUBE_API_KEY`):
   `python3 skripty/yt_comments.py <ссылки>` — или `--channel <канал>` для всего канала.
   Отбор релевантных роликов из большого канала — по заголовкам под нужную тему (см. как делалось в `kommentarii-razbor.md`, партия 2).
2. **Разобрать:** `python3 skripty/razbor_kommentov.py analitika/kommentarii/<...>/*.jsonl`
   → топ по лайкам (готовые крючки), фигуры вины, ярлыки, сигнал по углам, боли, биграммы.
3. **Сверить с речью Виолы** (`korpus/`, `baza/`): где язык аудитории совпадает с её словами — там и строим заход (это дало ключевой вывод лид-магнита).
4. **Выводы → в `ca-<продукт>.md`** и/или в живую таблицу (`ca-data.json` → `ca_sync.py`).

Дисклеймер по комментариям (действует всегда): это **язык и темы, не объёмы и не готовность платить**. Замер спроса — только анкета и событие.

## Синхронизация ЦА в Google-таблицу (repo → таблица, односторонняя)
1. Ключ сервис-аккаунта — тот же, что у `sheets_sync` (`VIOLA_SHEETS_CREDS_JSON` или `skripty/.google-creds.json`).
2. Таблицу ЦА расшарить на email сервис-аккаунта, доступ «Редактор».
3. Зависимости: `python3 -m pip install -r skripty/requirements-sheets.txt`.
4. `python3 skripty/ca_sync.py` (сухой прогон) → показать → `--apply`.

Скрипт создаёт недостающие вкладки и пишет значения; форматирование, твои доп-колонки и чужие вкладки не трогает. Правки контента — в `ca-data.json`. ID таблицы — в `ca-data.json` (`spreadsheet_id_default`) или `VIOLA_CA_SHEET_ID`.
