# analitika/kommentarii/

Сырьё аудитории — комментарии из-под контента Виолы. Это **данные аудитории,
не речь Виолы** — поэтому здесь, а не в `korpus/`.

Источники:
- **YouTube** — видео и Shorts, выгрузка через YouTube Data API (`skripty/yt_comments.py`).
- **Telegram** — чат канала `violamaro1`, разбор HTML-экспорта (`skripty/tg_comments.py`).

Сырые дампы (`.jsonl`/`.txt`, в т.ч. в подпапках) **не коммитим** — они gitignored и
регенерируются. В репозитории держим только разбор (`../kommentarii-razbor.md`,
`../tg-kommentarii-razbor.md`) и этот README. ID роликов по партиям — в разборе.

Форматы:
- YouTube, на каждое видео: `<videoId>.jsonl` (по комментарию на строку: автор,
  текст, лайки, дата, флаг «ответ») и `<videoId>.txt` (только тексты).
- Telegram: `tg-violamaro1.jsonl` (комментарии аудитории), `tg-violamaro1.txt`
  (только тексты), `tg-violamaro1.viola.txt` (реплики Виолы — её голос, но это чат,
  в `korpus/` автоматически не тащим).

Годятся как **язык аудитории и перечень тем**: для крючков и разметки контента — да;
как замер объёмов/долей — нет (комментируют самые вовлечённые, состав задан контентом).
