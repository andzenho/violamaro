# analitika/kommentarii/

Сырьё аудитории — комментарии из-под видео и Shorts Виолы, выгруженные через
YouTube Data API (`skripty/yt_comments.py`). Это **данные аудитории, не речь Виолы** —
поэтому здесь, а не в `korpus/`.

Формат на каждое видео:
- `<videoId>.jsonl` — по комментарию на строку: автор, текст, лайки, дата, флаг «ответ».
- `<videoId>.txt` — только тексты, для быстрого анализа языка/болей/фраз.

Годятся как **язык аудитории и перечень тем** (см. оговорку в `ca-analiz-v1.1.md`):
для формулировок крючков и разметки контента — да; как замер объёмов/долей — нет
(комментируют самые вовлечённые, состав задан выбором роликов).
