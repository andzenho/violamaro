# analitika/saity/

Сырьё распарсенных **чужих** сайтов через `/sait` (`skripty/sait.js`): лендинги
конкурентов, психологов, референсы офферов.

- Формат: `NN-slug.md` (текст в порядке чтения + структура: заголовки, CTA, цены,
  формы, ссылки). Рядом — `NN-slug.png` (скриншот), если сохраняли.
- Только исходники. Не редактировать, не чистить — как сняли.
- **В `baza/` не переносить.** База — голос и канон Виолы, здесь чужой текст.
  Отсюда материал идёт в анализ (позиционирование, офер), а не в тексты от лица Виолы.

Материал самой Виолы (её страницы) снимается в `korpus/`, как транскрипты.
