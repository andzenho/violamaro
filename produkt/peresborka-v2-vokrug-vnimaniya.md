# «Любовь и деньги» v2 — пересборка вокруг её внимания

13.08.2026 · **Что это:** как выглядит продукт после решений 13.08 (товар — её внимание, разборы как сердцевина, индивидуальность на массу, отбор по движению).
**Статус:** предложение. Источник правды по офферу и тарифам до отдельного решения — `prezentatsiya-lyubov-i-dengi.md`. Здесь показано, **что в ней меняется и почему**.

---

## Одна строка

**Месяц с Виолой, где каждую неделю разбирают вашу ситуацию её голосом. Программа держит каркас, разборы — то, ради чего остаются.**

## Что изменилось по сути

| | Было (презентация 12.08) | Стало |
|---|---|---|
| **Что продаём** | программу из 6 лекций | **её внимание**; лекции — каркас и график |
| **Сердцевина** | лекции + мастер-класс в финале | **еженедельный разбор вопросов потока голосом** |
| **Базовый тариф** | лекции и чат **без её ответов** | все разборы потока (чужие вопросы «на 5–30% мои») |
| **Лестница тарифов** | доступ к её голосу vs его отсутствие | **чей вопрос разбирают: общий поток → ваш лично → вы отдельно** |
| **Материалы** | тетрадь, практики, фразы | то же + **методичка потока** и **библиотека разборов прошлых потоков** |
| **Вход** | купил — зашёл | **задание до старта**, профиль эмпата, согласие на публикацию разборов |
| **Группа** | «сообщество эмпатов со всего мира» | то же, но **знакомства организуем принудительно** — сама не собирается |
| **Первый экран** | «овладейте суперспособностью» | **чем это отличается от «Эмпатии», которую вы прошли** |

# 1. Как выглядит неделя

| День | Что происходит | Чьё время |
|---|---|---|
| **Пн** | Лекция (запись, открывается в назначенный час, есть аудиоверсия) | записано заранее |
| **Вт–Ср** | Участники присылают вопросы. Приём закрывается в среду вечером | — |
| **Чт** | Вопросы группируются по темам: 100 человек → ~10 тем недели | редактор |
| **Пт** | **«Разбор недели»** — Виола отвечает по темам голосом, называя имена: «об этом спрашивают Марина, Ольга и ещё трое…» | **её, ~1 час** |
| **Сб** | Лекция + задание на неделю | записано заранее |
| **Вс** | Практика, тишина, куратор отвечает на бытовое и техническое | куратор |

**Четвёртая неделя** — живой мастер-класс с ответами в эфире.
**По итогам потока** — методичка: все разборы одним документом по темам, доступ навсегда.

⚠️ Ритм построен так, что её участие — **один блок в неделю**, а не постоянное присутствие в чате. Это единственный способ удержать нагрузку при росте продаж (арифметика — `gipoteza-produkt-vokrug-lichnosti §Часть 2`).

# 2. Тарифы: лестница по тому, чей вопрос разбирают

| | **Базовый**<br>*Слушаете все разборы* | **Полный**<br>*Разбирают ваш вопрос* | **Личный**<br>*Разбирают вас* |
|---|:---:|:---:|:---:|
| | **19 900 ₽** | **29 900 ₽** | **39 900 ₽** |
| **ЕСТЬ ВЕЗДЕ** | | | |
| 6 лекций + аудиоверсии, доступ навсегда | ✓ | ✓ | ✓ |
| **Разборы недели голосом Виолы — все, весь поток** | ✓ | ✓ | ✓ |
| **Библиотека разборов прошлых потоков** | ✓ | ✓ | ✓ |
| **Методичка потока по итогам** | ✓ | ✓ | ✓ |
| Живой мастер-класс | ✓ | ✓ | ✓ |
| Рабочая тетрадь, доска желаний, практики голосом, готовые фразы, Конституция эмпата | ✓ | ✓ | ✓ |
| Сообщество + куратор-выпускник | ✓ | ✓ | ✓ |
| **СО ВТОРОГО** | | | |
| **Ваш вопрос — один в неделю, с гарантией ответа** | — | ✓ | ✓ |
| Ваш вопрос на мастер-классе | — | ✓ | ✓ |
| **ТОЛЬКО В ЛИЧНОМ** | | | |
| Разбор на старте голосом: куда уходят силы, с чего начинать | — | — | ✓ |
| Разбор вашей доски желаний в финале | — | — | ✓ |
| **Мест** | без ограничений | без ограничений* | **[N]** |

*\* Лимит в «Полном» появляется, если продажи упрутся в её часы. Считается из одного числа — см. §6.*

**Почему лестница именно такая (сверка с каноном тарифов, `prezentatsiya §Принципы`):**
- **Правило 1 ✓** — материалы везде одинаковы, различие только в её внимании.
- **Правило 2 ✓** — в базовом метод целиком **и теперь настоящий товар**: разборы. Прежний базовый продавал то, что мы сами назвали неважным.
- **Правило 3 ✓** — шаг +10 000 против прибавки «мой вопрос разберут лично» — воспринимается дороже шага.
- **Правило 4 ⚠️** — лимит «Личного» по-прежнему требует её числа.

# 3. Что отвечает первый экран (уровень осведомлённости 4–5)

Аудитория не спрашивает «что такое эмпатия». Спрашивает: **чем это отличается от того, что я у вас уже прошла.** Ответ — четыре пункта, все проверяемые:

1. **«Эмпатия» — про то, как устроен ваш дар. Здесь — куда его направить:** в отношения, в дело, в деньги.
2. **Разбирают вашу ситуацию, а не тему вообще.** Каждую неделю вопросы потока — с ответами голосом.
3. **Доступ навсегда** (в «Эмпатии» — шесть месяцев, и участники тревожно переспрашивали дату).
4. **Месяц, а не три.** Формат собран под тех, кто уже в процессе.

# 4. Индивидуальность на массу — что встроено в продукт

| Механизм | Где живёт в продукте |
|---|---|
| Имена в общем ответе | формат «Разбора недели» |
| Гарантия ответа | второй тариф, один вопрос в неделю |
| Профиль на входе | тест «ваш тип эмпата» → материалы под тип |
| Статус | «ваш вопрос вошёл в методичку потока» |
| Внимание сверстников | малые группы по 5–6, знакомства назначаем сами |
| Куратор-выпускник | быт, техника, VPN — снимает это с Виолы |
| Два личных касания | только «Личный»: вход и финал |

# 5. Отбор на входе (следствие установки «работаем с теми, кто движется»)

1. **Задание до старта.** Небольшое, на 15 минут. Кто не сделал — не начал; отсев без единого отказа.
2. **Анкета:** профиль эмпата + вопрос о текущем состоянии и наблюдении у специалиста (граница с клиникой, `ca-master §6.1`).
3. **Согласие на публикацию разборов** — пункт оферты плюс возможность пометить вопрос приватным.
4. **Тон текстов** — «выделять, а не утешать»: кого зовём, тот и приходит.
5. **Первым делом пишем выпускникам** трёх чатов «Эмпатии»: там прямая заявка «оповестите, когда будет курс „Любовь и Деньги для Эмпата"».

---

# 6. Что нужно от Виолы, чтобы это посчитать

1. **Сколько тем в неделю она разбирает голосом** (не «сколько ответов»). Из этого числа выводится всё: лимит мест, потолок продаж, нужен ли лимит во втором тарифе.
2. **Согласна ли**, что её ответы — главный товар, а лекции каркас. Это её нагрузка и её решение.
3. **Согласие участников прошлых потоков** на публикацию разборов — это библиотека к старту, а не к финалу.
4. Прежние открытые вопросы остаются: цены, лимит «Личного», дата старта, «месяц против её же 90 дней».

# 7. Что нужно от команды

- **Редактор разборов** (транскрипт → группировка → обезличивание → публикация в пятницу). Без назначенного человека строку в оффер не ставим.
- **Куратор-выпускник** на быт и технику.
- **Ведущий малых групп** — хотя бы сценарий первой встречи.

---

# 8. Риски этой конструкции

1. **Каннибализация второго тарифа:** если чужих разборов хватает, зачем платить за свой вопрос. Проверить на кастдеве.
2. **Нагрузка на неё растёт с продажами** — медленнее, чем при личных ответах, но растёт. Лимит в «Полном» должен быть готов заранее.
3. **Срыв ритма.** Пятничный разбор — обещание с датой. Один пропуск бьёт сильнее, чем слабая лекция.
4. **Приватность.** Публикация разборов без аккуратного обезличивания ломает безопасность, за которую платят («Стыдно, что я открылась»).
5. **VPN.** Всё, что живёт в Telegram и Zoom, для России под VPN. Дублирование на GetCourse и записи — обязательны.
