# produkt/

Материалы по продуктам линейки: программы, структуры, лендинги, цены, условия.

## Что где

**Флагман «Любовь и деньги» (август 2026, под кастдев)**
- `prezentatsiya-lyubov-i-dengi.md` — **источник правды.** Оффер, программа, тарифы, плюс внутренние заметки: обоснование каждого решения, правки Виолы и продюсера, что осталось закрыть.
- `odnostranichnik-sozvon-lyubov-i-dengi.md` — та же клиентская часть сжато, для показа на созвоне.
- `programma-lyubov-i-dengi-v1.md` — методическая начинка шагов.
- `docs/` — собранный .docx для команды. Пересобирается `node skripty/gen_prezentatsiya_docx.js <файл>`.

*При расхождении между этими файлами прав `prezentatsiya-lyubov-i-dengi.md`.*

**Запуск флагмана**
- `marafon-po-sferam.md` — **марафон как прогрев и продажа флагмана.** Шесть эфиров по неделям программы, структура эфира, правило «один приём из недели бесплатно», вопросы из комментариев, продажа с первого дня, календарь. ⚠️ Опирается на программу от продюсера 13.08 (6 недель) и на невлитую ветку `claude/product-target-audience-tinczi`.

**Продажи**
- `karta-smyslov-i-argumentov.md` — карта смыслов ЦА (боли, страхи, желания, возражения) с аргументом к покупке на каждый и симуляцией диалогов. Инструмент для созвонов и лендинга.

**Верхний уровень**
`strategiya.md` — стратегия запуска · `voronka.md` — канон воронки · `transformatsii.md` — канон трансформаций · `transformatsiya-za-dengi.md` — какую метаморфозу продавать.

**Материал от Виолы и по Виоле**
`sozvon-viola-11.08-itogi.md` — решения с созвона (разворот на эмпатов) · `sozvon-11.08-razbor-dlya-komandy.md` — тот же созвон, развёрнуто для команды · `fakty-viola.md` — цифры и решения · `produkty-viola-staryye.md` — её старые лендинги: цены, тарифы, образы.

**Рабочие разборы** (сырьё решений, при спорах поднимать их)
`efir-lyubov-i-dengi-razbor.md` · `vebinar-empaty-dengi-razbor.md` · `dengi-dlya-empata-razbor.md` · `flagman-sborka-jtbd.md` · `blok-do-posle-prorabotka.md`.

Устаревшие офферы — в `arhiv/ofery-promezhutochnye/`, при обычной работе не читать.
