# produkt/

Материалы по продуктам линейки: программы, структуры, цены, условия.

## Флагман «Любовь и деньги»

- **`prezentatsiya-lyubov-i-dengi.md` — источник правды.** Оффер, программа, тарифы плюс внутренние заметки: обоснование каждого решения, правки Виолы и продюсера, что осталось закрыть.
- `odnostranichnik-sozvon-lyubov-i-dengi.md` — та же клиентская часть сжато, для показа на созвоне.
- `programma-lyubov-i-dengi-v1.md` — методическая начинка: практики, техники, распределение по лекциям. Клиентских формулировок здесь нет намеренно.
- `docs/` — собранный .docx для команды.

**Правило одного источника.** Клиентский текст правится только в презентации. Дальше:

```
node skripty/gen_prezentatsiya_docx.js      # пересобрать .docx из презентации
python3 skripty/sverka_offera.py            # проверить, не разошлись ли копии
```

Генератор читает markdown, своей копии текста не держит. Сверка проверяет цены, названия лекций, состав обещанного и свежесть .docx; возвращает 1 при расхождении. **При расхождении правим копии под источник, не наоборот.**

## Продажи
`karta-smyslov-i-argumentov.md` — карта смыслов ЦА (боли, страхи, желания, возражения) с аргументом к покупке на каждый и симуляциями диалогов. Инструмент для созвонов и лендинга.

## Верхний уровень
`strategiya.md` — стратегия запуска: линейка, цены, план, риски, открытые решения · `voronka.md` — канон воронки: франшиза, витрина и двигатель, лестница, правила текстов · `transformatsii.md` — канон трансформаций · `transformatsiya-za-dengi.md` — карта внимания канала и какую метаморфозу продавать.
