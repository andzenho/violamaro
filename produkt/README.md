# produkt/

Материалы по продуктам линейки: программы, структуры, лендинги, цены, условия.

## Что где

**Флагман — практикум «Прикладная эмпатия» (осень 2026, под визирование и кастдев)**
- `praktikum-dlya-empatov.md` — **источник правды.** Оффер, шесть недель по программе Виолы, два тарифа (14 900 / 29 900 на предзаписи, 50 мест в «Полном»), плюс внутренние заметки: канон тарифной сетки, правки Виолы по голосу, арифметика её часов, открытые вопросы, риски.

*Прогрев — тест и пять эфиров — идёт под отдельной рамкой «Я ЭМПАТ» (`praktikum §12`, `marafon-po-sferam.md`).*

*Текст лендинга в Google Docs (копия для вёрстки, не источник правды): [Прикладная эмпатия — текст лендинга](https://docs.google.com/document/d/1pbdca-brUxxZ57VOm3y5LX4lQxqaMWxl5Q1-1y717e8/edit)*

*Прежний флагман «Любовь и деньги» (презентация, одностраничник, программа v1, docx) — в `arhiv/lyubov-i-dengi/`. Название снято 13.08, конструкция пересобрана вокруг её внимания.*

**Событие «Неудобные» (11–13 сентября, 3 000 ₽) — платный вход перед флагманом**
- `neudobnye.md` — **источник правды по коммерции и операциям.** Цена, оплата, площадка, состав дней, скидка на флагман, механика дефицита, как событие продаётся внутри теста, и список открытых вопросов.
- `sobytie-5-dney.md` — конструкция и смыслы: почему такая витрина, диагноз, красные линии.
- `sobytie-lending.md` — текст лендинга по экранам.
- `prilozhenie-1-neudobnye.md` — юридический состав: раздел 5 под вставку в Приложение № 1 оферты.

*Витрина события живёт ещё и внутри теста «Колесо эмпата» (`docs/koleso/index.html`, константа `OFFER`) — это то, что реально читает покупатель.*

**Запуск флагмана**
- `marafon-po-sferam.md` — **календарь запуска и пять эфиров.** Даты по таблице запуска (пересборка партнёра 13.08), две разные работы эфиров (до события — анкета, после — продажа), темы и раскладка, структура эфира, правило «одну технику из недели», вопросы из комментариев, техконтур, что нужно к 15.08. Плюс ценовая лестница по четырём окнам продаж и четыре замечания к ней (разрывы без цены, защита «Личного», нижний тариф без карты техник).
