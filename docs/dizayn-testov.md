# Дизайн тестов и квестов — стандарт

Решение продюсера 28.08.2026. Виола попросила светлее, референс дал продюсер — Мел Робинс. Из трёх показанных вариантов выбран **«Светлая Виола»**.

Стандарт для **всех** интерактивных страниц: тесты, квесты, мини-аппы. Эталон живёт в `docs/koleso/index.html`, оттуда и копировать.

---

## 1. Что взято у Мел Робинс, а что нет

Её система строится на трёх вещах: **почти белый фон, почти чёрный текст, один цвет-маркер на главной фразе**. Плюс много воздуха и крупный жирный гротеск вместо декоративных заголовков. Всё это мы берём.

**Жёлтый маркер не берём.** Жёлтый у Мел Робинс — личная подпись, привязанная к её лицу, очкам и книгам. Часть нашей аудитории её знает, и копия читалась бы как копия. Маркер остаётся приёмом, но в тёплом золоте Виолы: тест и сайт флагмана не разъезжаются, а узнаваемость остаётся её собственной.

Источники по её системе: [ndny studio о бренде Мел Робинс](https://ndnystudio.squarespace.com/blog/mel-robbins-compelling-brand-story-amp-identity) · [Skye High Interactive, кейс редизайна](https://www.skyehighinteractive.com/case-study/mel-robbins)

## 2. Палитра

### Светлая тема

| Переменная | Значение | Где |
|---|---|---|
| `--ground` | `#FBFAF7` | фон страницы |
| `--surface` | `#FFFFFF` | карточка |
| `--surface-2` | `#F5F1EA` | вложенные блоки |
| `--ink` | `#191512` | основной текст и **заголовки** |
| `--ink-soft` | `#4A423B` | вторичный текст |
| `--ink-mute` | `#867C71` | подписи, сноски |
| `--line` | `#E8E2D8` | тонкие линии |
| `--line-strong` | `#D3C9B9` | рамки полей и кнопок-ответов |
| `--accent` | `#191512` | акценты в буквах = цвет текста, коричневого в тексте нет |
| `--accent-soft` | `#F6E3BE` | фон акцентных плашек |
| `--mark` | `#F6D98C` | **маркер** |
| `--mark-ink` | `#191512` | текст под маркером |
| `--btn-bg` | `#191512` | кнопка, плоская |
| `--btn-ink` | `#FFFFFF` | текст кнопки |

### Тёмной темы нет

Автопереключение по `prefers-color-scheme` снято 28.08. Пока оно стояло, человек с тёмным режимом в системе видел тёмную страницу и справедливо считал, что дизайн не менялся. Виола просила светлый — значит светлый у всех.

Тёмная палитра в файле осталась и включается вручную атрибутом `data-theme="dark"`. Вернуть автоматику — снова обернуть её в `@media`, одна строка.

Обязательно: `<meta name="color-scheme" content="light">`. Без него браузер в тёмном режиме сам перекрашивает поля ввода и полосу прокрутки, и на белой карточке появляются чёрные прямоугольники.

## 3. Правила, а не только цвета

**Коричневого в буквах нет вообще.** На светлом фоне он выглядит грязно (решение продюсера 28.08). Цветной элемент ровно один — маркер. Тёплое золото осталось только в заливках: маркер, плашки дат, фигура колеса. Иерархию держат кегль и жирность, а не цвет.

**Контента в коробке нет.** Рамка, тень и скруглённый угол делали из экрана окошко. Контент лежит прямо на странице, как слайд карусели, и работает не рамка, а воздух между блоками.

**Маркер по заголовку — главный приём.** Из-за него экран читается как другой дизайн, а не как те же буквы другого цвета.

**Шрифт один — Golos Text, 400–700.** Prata убрана 28.08. Засечки читаются тяжело на маленьком кегле, а в тесте двадцать четыре экрана подряд, и каждый надо прочитать внимательно. Заголовки: `font-weight: 700`, `letter-spacing: -.02em`. Крупные цифры — там же, жирным, с `tabular-nums`.

**Кнопка плоская.** Градиент и коричневый делали её мягкой. Плотный прямоугольник цвета текста читается как «нажми», а не «посмотри».

**Маркер через `box-shadow`, не через `padding`:**

```css
.hl {
  background: var(--mark); color: var(--mark-ink);
  box-shadow: 0 0 0 .18em var(--mark);
  border-radius: 2px; font-weight: 600;
}
```

Padding разрывал бы межстрочный интервал и выталкивал соседние строки. Тень переносится вместе со строкой.

**Маркер — один на экран.** Он работает ровно до тех пор, пока выделяет единственную вещь. Два маркера на экране не выделяют ничего.

## 4. Технические ограничения, которые не обсуждаются

Их нарушение ломает страницу у части аудитории, а не «выглядит хуже».

- **Шрифты вшиты в файл** через `@font-face` с base64. Страница живёт внутри Телеграма, внешний запрос здесь уже стоил нам белого экрана.
- **Никаких `color-mix`, `replaceChildren`, `fit-content`** — старые вебвью Андроида их не понимают. Вместо `fit-content` — `display: table`.
- **Иконки — вставленный SVG** с `stroke="currentColor"`, не эмодзи и не иконочный шрифт.
- **Проверять на 320 пикселях.** Горизонтальной прокрутки быть не должно ни на одном экране.

## 5. Что ещё не переведено

`docs/index.html` — старый тест «Есть у вас способности эмпата?». Он живой, его трогать без отдельного слова продюсера нельзя. Палитру туда перенести можно за один заход, когда он скажет.
