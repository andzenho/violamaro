# docs/ — то, что опубликовано

GitHub Pages раздаёт эту папку после пуша в `main`. Адрес — https://andzenho.github.io/violamaro/

- `index.html` — тест **«Какой ты эмпат»** (первый, с 14.08). Единственный исходник вёрстки.
- `koleso/index.html` — тест **«Колесо эмпата»** (второй, с 28.08). Адрес — /violamaro/koleso/
- `dizayn-testov.md` — правила оформления страниц тестов: сетка, типографика, поведение на телефоне.

Правим вёрстку прямо здесь. Смысловые исходники теста — в `produkt/`:
`test-empat.md` (вопросы, типы, разбор) и `test-empat-chistovik.md` (чистовые
формулировки). Меняем смысл — там, меняем вёрстку — здесь.

⚠️ Копий этих файлов нигде больше не держим: они расходятся. Прежняя копия
`produkt/test-empat.html` снята 15.08, архивная копия из `arhiv/tehnicheskoe/`
снята 28.08 при слиянии веток.
