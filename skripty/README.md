# skripty/

Служебные скрипты. По умолчанию — только стандартная библиотека Python 3.

- `plan.py` — **с него начинается день.** Что горит по контент-плану: просрочено,
  сегодня, ближайшие дни, плюс опубликованное без проставленной ссылки. Читает
  `kontent/kp/`, ничего не меняет, работает мгновенно и без модели — то есть
  разведка «что делать» стоит ноль токенов. Команда `/den` делает всё, что он показал.
  `python3 skripty/plan.py [--dney 14] [--vse]`
- `proverka.py` — проверка готового текста от лица Виолы перед отправкой.
  `python3 skripty/proverka.py путь/к/тексту.txt`
- `razbor.py` — разбор нового транскрипта: что нового относительно базы.
  `python3 skripty/razbor.py korpus/новый.txt`
- `perenos.py` — расставить переносы строк в транскрипте по границам предложений.
  **Обязательный шаг приёмки в `korpus/`.** Меняет только пробельные символы и
  сам сверяет текст до и после — при малейшем расхождении не пишет. Без него
  транскрипт остаётся одним абзацем на файл, и один `grep` по нему возвращает
  файл целиком: поиск «чувство вины» по `02-otvety.txt` стоил 12 671 токен
  (весь файл — 12 672), стал 2 221.
  `python3 skripty/perenos.py korpus/*.txt [--primenit]`
- `karta_korpusa.py` — оглавление большого файла корпуса по разметке страниц:
  номер страницы, номер строки, заголовок. Дальше читаем нужный кусок через
  `offset`/`limit`, а не файл целиком (методичка — 80–130 тыс. токенов).
  Ничего не пишет на диск.
  `python3 skripty/karta_korpusa.py korpus/06-….txt [--iskat поле]`
- `karta.py` — пересобрать `karta.md`: индекс всех файлов репозитория (путь, вес
  в токенах, суть одной строкой). Запускать после любого изменения структуры —
  добавили, переименовали или удалили файл. Описание файла берётся из строки
  `описание:` в нём самом, иначе из первого заголовка.

- `oglavlenie.py` — вставить в тяжёлый файл оглавление с **номерами строк**,
  чтобы читать его точными кусками, а не вслепую. Идемпотентен: при повторном
  запуске блок переписывается, номера остаются верными.
      python3 skripty/oglavlenie.py produkt/praktikum-vnutrennie-zametki.md
      python3 skripty/oglavlenie.py --vse    # все файлы тяжелее 10 тыс. ток.
  Не запускать на файлах с дословным текстом страниц (`*-promt-gotovyy.md`,
  `*-lending.md`) — там оглавление попадёт в публикуемый текст.

- `ves.py` — сколько токенов весит файл или папка. Нужен, чтобы решение «читать
  целиком или искать грепом» принималось по цифре: `kanon-empat.md` — 2,3 тыс.
  токенов, методичка из `korpus/` — 130 тыс. Считает питоном: `wc -w` и `wc -m`
  на кириллице врут, если в системе не выставлена UTF-8-локаль.
  `python3 skripty/ves.py baza/ [--papki]`
- `yt_comments.py` — выгрузка комментариев из-под видео/Shorts через YouTube Data
  API v3 (работает из облака, не скрейпинг). Только stdlib; нужен ключ
  `YOUTUBE_API_KEY`. Сырьё кладётся в `analitika/kommentarii/`.
  `python3 skripty/yt_comments.py <ссылка> | --channel <канал>`
- `razbor_kommentov.py` — разбор собранных комментариев для анализа ЦА: топ по
  лайкам, фигуры вины, ярлыки, сигнал по углам С1–С5, боли, биграммы. Только stdlib.
  `python3 skripty/razbor_kommentov.py analitika/kommentarii/<...>/*.jsonl`
- `sheets_sync.py` — синхронизация контент-плана из `kontent/kp/` в Google-таблицу
  «Рабочее пространство» (репозиторий → таблица, только колонки «Тема / идея» и
  «Текст поста»). Установка и настройка — `kontent/kp/README.md`.
  `python3 skripty/sheets_sync.py --list-tabs | (без флага) | --apply`
- `ca_sync.py` — синхронизация анализа ЦА из `analitika/ca-data.json` в Google-таблицу
  «ЦА и продукты» (репозиторий → таблица, лист = вкладка; форматирование и твои
  доп-колонки не трогает). Настройка — `analitika/README.md`.
  `python3 skripty/ca_sync.py --list-tabs | (без флага) | --apply`

- `lending_promt.py` — сборка промпта для Claude Design: бриф + текст страницы
  дословно (между метками ✂️), чтобы текст в вёрстке не разошёлся с источником
  правды. Два набора: флагман «Прикладная эмпатия» (по умолчанию) и событие
  «Неудобные» (`--sobytie`). Собранный файл перезаписывается, правки вносить в
  бриф и в текст. Только stdlib.
  `python3 skripty/lending_promt.py [--sobytie] [--apply | --stdout]`

- `bot_probe.py` — кому бот может написать первым: прогоняет список Telegram ID
  через Bot API (`sendChatAction`, без видимых сообщений) и по каждому даёт
  вердикт — reachable / no_access (нет разрешения писать) / blocked. Нужен для
  аудита людей из мини-аппа, которые в чат бота не писали. Только stdlib; токен —
  `TG_BOT_TOKEN`. Вход — файл с ID по строке или CSV с колонкой `userId`.
  `TG_BOT_TOKEN=... python3 skripty/bot_probe.py ids.txt [--out otchet.csv]`

- `sait.js` — открыть сайт настоящим Chromium и снять сырьё: текст в порядке
  чтения, структуру (заголовки, CTA, формы, цены), ссылки, скриншот. Нужен там,
  где `WebFetch` бесполезен: Tilda, Taplink, любой SPA. Node, не Python; разовая
  настройка — `sh skripty/sait_setup.sh`. Вызывается и командой `/sait`.
  `node skripty/sait.js <адрес>`

`sheets_sync.py` и `ca_sync.py` — **единственные скрипты с внешними зависимостями**
(Google Sheets API нельзя вызвать без библиотеки), ставятся из
`skripty/requirements-sheets.txt`. Оба используют один ключ сервис-аккаунта.
