# baza/ — база знаний (источник правды)

Сюда кладём только **проверенные** материалы, переработанные из корпуса, с пометкой источника.

Файлы базы:
- `golos-viola.md` — голос Виолы: лексика, ритм, образы, запреты. **Читать целиком перед любым текстом от её лица.**
- `kanon-empat.md` — канон по теме эмпата: самообман, пробуждение, состояние разблокированной силы. Тема флагмана.
- `kanon-lyubov-i-dengi.md` — канон по теме «любовь и деньги»: наполненность, изобилие, деньги для эмпата, 10 привычек изобилия. Смысловое ядро флагмана.
- `kanon-viny.md` — канон по теме вины. После разворота 11.08 — механизм внутри продукта и тема лид-магнита, не витрина флагмана.
- `tehniki-viola.md` — техники и упражнения.
- `printsipy-viola.md` — принципы и красные линии.
- `reestr-istochnikov.md` — реестр источников: что разобрано, когда и что дало.

Правило меток внутри базы:
- `[Д]` — дословные слова Виолы, можно ставить в тексты как есть.
- `[П]` — пересказ.
- `[В]` — невподтверждённый вывод, **в тексты не использовать вообще**.

Ничего не добавлять в базу без подтверждения продюсера (правило «В базу?»).
