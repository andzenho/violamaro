## Правило работы

Один транскрипт может питать несколько тематических файлов. Порядок: транскрипт кладётся в корпус, размечается один раз, дальше материал расходится по темам. Техники не копируются в темы, тема ссылается на номер техники.

Формулировка техники живёт только в `tehniki-viola.md`. Если она меняется, правится одно место.

**Метка источника [ВИД]** — её видео-ролики на YouTube (`@violamaro`), сняты под камеру = отредактированный регистр (как [ЗАП]). Даны транскриптами продюсером (в облаке YouTube не тянется).

**Метка источника [ЭФИР]** — запись живого эфира/лекции курса (сырая речь, как [ОТВ], но монолог под аудиторию). Клиентские упоминания обезличены в самой лекции.

**Метка источника [ВЕБ]** — запись бесплатного вебинара (живая речь под аудиторию, сырая ASR-расшифровка, очищена при переносе в корпус). Дословность ниже, чем в [ВИД]/[ЗАП]: формулировки помечать преимущественно [П]; [Д] — только для узнаваемых её оборотов.

**Контрольный материал, не корпус:** наш сценарий лид-магнита, ею забракованный. Используется только для сравнения «наш текст против её текста» на одном содержании.

## Чего в корпусе нет

- **Письменного регистра.** Ни одного текста, написанного ею руками. Раздел 8 файла по голосу остаётся гипотезой, пока не появится.
- **Её правок нашего письменного текста.** Ближайший источник: лендинг «Лабиринт» в Google Drive, пять итераций, возможны комментарии.
- **Выгрузки её ИИ-агента.** Промпт отдан, результата нет. Ожидается: её постоянные инструкции, пары «его вариант и её правка», правки по содержанию.
- **Обещанного ею.** Пара листов с формулировками, документ про различие вины и стыда, формулировки из клиентских файлов.

## Приоритет следующих источников

1. Правки лендинга. Закрывает письменный регистр и границу «моё и не моё» одновременно.
2. Выгрузка агента. Может закрыть половину гайда по голосу готовыми правилами.
3. Транскрипты по темам за пределами вины. Каждая новая тема требует своего материала, из вины она не выводится.
