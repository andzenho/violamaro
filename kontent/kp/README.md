# kontent/kp/ — контент-план, синхронизируемый с Google-таблицей

Здесь лежит **источник правды** по контент-плану. Отсюда контент уезжает в
Google-таблицу «Виола // Рабочее пространство», во вкладки КП. Направление
одностороннее: **репозиторий → таблица**. В таблице руками правим что угодно,
кроме двух колонок — `Тема / идея` и `Текст поста` (`Суть`): их перезаписывает
скрипт из этой папки.

Скрипт пишет **только** в эти две колонки и **только** в уже существующие
строки (по дате). Он не добавляет и не удаляет строки, не трогает разметку,
формулы и объединённые ячейки. Дизайн таблицы не ломается.

## Структура

```
kontent/kp/
  <папка вкладки>/
    _tab.txt              # первая строка — ТОЧНОЕ имя вкладки в таблице
    2026-08-07--1.md      # посты; дата берётся из имени файла
    2026-08-07--2.md      # два поста на одну дату — суффикс --1, --2, ...
    2026-08-08.md         # один пост на дату
```

Папку можно называть как удобно — важно только `_tab.txt` внутри неё.
Точные имена вкладок в таблице узнать так:

```
python3 skripty/sheets_sync.py --list-tabs
```

Строки с `[КП]` — это вкладки контент-плана. Для каждой, которую хочешь
наполнять из репозитория, заведи здесь папку и `_tab.txt` с её именем.

## Формат файла поста

```
тема: идея поста и его цель, одной строкой
статус: план
---
Здесь текст поста — итоговый контент.

Многострочно, с пустыми строками между абзацами. Всё, что после «---»,
уедет в колонку «Текст поста» как есть.
```

- `тема:` → колонка **Тема / идея**. Обязательна.
- Текст после `---` → колонка **Текст поста** (или **Суть**).
- `статус:` и любые другие поля в шапке — для нас, в таблицу **не** пишутся
  (скрипт трогает только две колонки).
- Если текста ещё нет (есть только идея) — оставь файл без `---` и без тела.
- Сопоставление со строками таблицы — по дате. Если на дату несколько постов,
  они лягут в строки этой даты сверху вниз в порядке имён файлов. Если постов
  больше, чем строк на эту дату в таблице, — добавь строки в таблице вручную,
  лишние скрипт пропустит и предупредит.

## Первичная настройка доступа (один раз)

Скрипту нужен сервис-аккаунт Google (обычный коннектор умеет только читать).

1. [Google Cloud Console](https://console.cloud.google.com/) → создать проект
   (или взять существующий).
2. Включить **Google Sheets API** для проекта.
3. Создать **сервис-аккаунт**, у него — ключ формата **JSON**, скачать.
4. Положить ключ в `skripty/.google-creds.json` (уже в `.gitignore`,
   в репозиторий не попадёт).
5. Открыть таблицу → «Настройки доступа» → добавить **email сервис-аккаунта**
   (вида `...@....iam.gserviceaccount.com`) с ролью **Редактор**.

Библиотеки (единственное место в проекте с внешними зависимостями):

```
python3 -m pip install -r skripty/requirements-sheets.txt
```

## Как синхронизировать

```
python3 skripty/sheets_sync.py --list-tabs   # проверить, что видит вкладки
python3 skripty/sheets_sync.py               # сухой прогон: покажет, что изменит
python3 skripty/sheets_sync.py --apply       # записать в таблицу
```

Сначала всегда сухой прогон — он показывает каждую ячейку «было → стало».
Убедился — тогда `--apply`.
