# kontent/kp/ — контент-план для Google-таблицы

Здесь лежит **источник правды** по контент-плану. Отсюда контент попадает в
Google-таблицу «Виола // Рабочее пространство», во вкладки КП — в две колонки:
`Тема / идея` и `Текст поста` (`Суть`). Остальное в таблице не трогаем.

Есть два способа перенести контент в таблицу. Начни с простого.

---

## Способ 1 (простой, без настроек) — скопировать и вставить

Ничего устанавливать и подключать не надо.

```
python3 skripty/kp_export.py
```

Скрипт соберёт весь контент и сохранит в `kontent/kp/_dlya_vstavki.txt`.
Открываешь этот файл — там по каждой дате два готовых блока:
① «Тема / идея» и ② «Текст поста». Копируешь каждый в нужную ячейку таблицы
(строку находишь по дате).

Плюс: ноль настройки. Минус: вставляешь руками.

---

## Способ 2 (автоматический) — позже, если захочешь

Скрипт `skripty/sheets_sync.py` сам пишет в таблицу (только в те же две
колонки, только в существующие строки, дизайн не ломает). Требует разовой
настройки доступа Google (сервис-аккаунт). Инструкция — в конце файла.
Пока не настроено — пользуйся Способом 1.

---

## Как это устроено (папки и файлы)

```
kontent/kp/
  <папка вкладки>/
    _tab.txt              # первая строка — ТОЧНОЕ имя вкладки в таблице
    2026-08-07--1.md      # посты; дата берётся из имени файла
    2026-08-07--2.md      # два поста на одну дату — суффикс --1, --2, ...
    2026-08-08.md         # один пост на дату
```

Папку можно называть как удобно — важно `_tab.txt` внутри с точным именем
вкладки.

### Формат файла поста

```
тема: идея поста и его цель, одной строкой
статус: план
---
Здесь текст поста — итоговый контент.

Многострочно, с пустыми строками между абзацами.
```

- `тема:` → колонка **Тема / идея**. Обязательна.
- Текст после `---` → колонка **Текст поста** (или **Суть**).
- Если текста ещё нет (только идея) — файл без `---` и без тела.
- Несколько постов на дату лягут в строки этой даты сверху вниз, в порядке
  имён файлов.

## Настройка Способа 2 (сервис-аккаунт Google)

Нужно, только если хочешь автоматическую запись. Карта/оплата не требуются
(окно про «бесплатный период» можно пропустить).

1. [Google Cloud Console](https://console.cloud.google.com/) → создать проект.
2. Включить **Google Sheets API**.
3. Создать **сервис-аккаунт**, у него ключ **JSON**, скачать.
4. Файл переименовать в `.google-creds.json` и положить в `skripty/`
   (он в `.gitignore`, в репозиторий не попадёт).
5. В таблице → «Настройки доступа» → добавить **email сервис-аккаунта**
   (`...@....iam.gserviceaccount.com`) с ролью **Редактор**.
6. Библиотеки: `python3 -m pip install -r skripty/requirements-sheets.txt`

Запуск:

```
python3 skripty/sheets_sync.py --list-tabs   # проверить вкладки
python3 skripty/sheets_sync.py               # сухой прогон: что изменит
python3 skripty/sheets_sync.py --apply       # записать в таблицу
```
