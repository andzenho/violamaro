# kontent/scenarii/ — сценарии коротких видео

Shorts и Reels — **главный источник трафика и главный рычаг запуска**. Собственная аналитика говорит это прямо: «рычаг — объём трафика (Shorts → лид-магнит), не идея» (`analitika/anketa-pervye-dannye.md`). Канал даёт ~15 000 ежедневных зрителей, 116 млн просмотров всего.

До 13.08.2026 сценариев в репозитории не было вообще: весь объём работы уходил в продукт, который ещё никому не продан.

## Что здесь лежит
Один файл — один сценарий. Имя: `<дата>--<короткое-имя>.md`, дата — планируемая съёмка.

```
тема: о чём ролик и на какую боль бьёт, одной строкой
тема-канала: эмпат-сила | токсик/манипуляции | отпустить | деньги-эмпата | доброта-сила
цель: узнавание | переход в Telegram | прогрев к продукту
статус: идея | сценарий | у Виолы | снято | опубликовано
хронометраж: 45–60 сек
---
[крючок — первые 3 секунды, ставит их вопрос их словами]

[тело — механизм её словами]

[замок — что делать / куда идти]
```

## Правила
1. **Голос.** Перед написанием — `baza/golos-viola.md` целиком плюс тематический файл базы. Не по памяти.
2. **Крючок — их слова, не наши.** Банк дословных фраз: `analitika/ca-voc.md` раздел А (эмпат/деньги), раздел Б (вина/расставания). Между разделами не смешивать — это разные люди с разными деньгами.
3. **Куда бьём.** Карта внимания канала (`produkt/transformatsiya-za-dengi.md`): манипуляции/токсик 18 млн, доброта=сила 12 млн при рекордных 199 тыс. на ролик, отпустить 10,4 млн, энергия/ресурс 3,4 млн при 94 тыс. на ролик. Вина как заголовок — 0,65 млн, в шестьдесят раз меньше.
4. **Красные линии базы** действуют полностью: без обещаний результата, без регалий в её прямой речи, без заочных диагнозов, обезличивание случаев, двойная гендерная разметка, термин — после бытового объяснения.
5. **Проверка перед отправкой Виоле:** `python3 skripty/proverka.py <файл>`.
6. **Замок ведёт в Telegram** — единственное место, где мы собираем аудиторию.

## Чего не делать
- Не оспаривать идентичность «эмпат»: она гордая и племенная. Отрицаем не дар, а убеждение «это слабость».
- Не обещать «стать неуязвимой / жёсткой»: ядро аудитории это отторгает (167 лайков под «вы предлагаете модель холодного человека»).
- Не выносить «вину» в крючок ролика под эмпат-аудиторию — она двигатель, а не витрина.
