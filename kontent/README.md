# kontent/

Готовый и черновой контент: посты, сценарии коротких видео, описания YouTube.
Тексты от лица Виолы — только после проверки через `skripty/proverka.py`.

## Что где

- **`kp/`** — **источник правды по контент-плану**, синхронизируется в Google-таблицу. Одна папка на вкладку (канал), файлы постов по датам `YYYY-MM-DD[--N].md`. Формат, статусы и настройка — `kp/README.md`.
  - `kp/strategiya-kontent-plana.md` — **главный документ по контенту**: сквозные правила, кодекс честности, рамки каналов, кран трафика, ЭГО-подпитка.
- **`opisaniya-youtube.md`** — правила описаний и закрепов под ролики, библиотека крючков.
- **Рабочие файлы с датой в имени** (`dlya-violy-*`, `podkast-tezisy-*`) — разовые задания и опоры, переданные Виоле или команде. Живут до исполнения, потом их можно чистить.

⚠️ **Порядок файлов в дате важен.** Если на дату больше одного поста, у **всех** файлов должен быть суффикс `--1`, `--2`, `--3`. Файл без суффикса сортируется после `--2` и посты уезжают в таблице не в те строки.
