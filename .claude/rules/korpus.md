# Работа с корпусом

`korpus/` — сырьё: неотредактированные транскрипты, ничего больше.

- Переработка идёт только `korpus → baza`, **никогда наоборот**.
- Снимаются плагином `/watch`, кладутся как есть — не править, не причёсывать.
- Приёмка и правила чтения — `korpus/README.md`.

## ⚠️ Вес
Здесь лежат самые тяжёлые файлы репозитория. Методички — 60–110 тыс. токенов
каждая. **Целиком не читать никогда.** Порядок: `python3 skripty/ves.py <путь>`
→ `grep -n` по теме → `Read` с `offset`/`limit` вокруг найденных строк.
Карта корпуса — `python3 skripty/karta_korpusa.py`.
