# Работа с контентом

`kontent/kp/` — **источник правды по контент-плану**, синхронизируется в
Google-таблицу. Одна папка на вкладку, `_tab.txt` = точное имя вкладки, файлы
постов по датам (`ГГГГ-ММ-ДД.md`, несколько за день — `--1`, `--2`).
Формат поста — `kontent/kp/README.md`.

Имена папок латиницей (`tg-osnova`, `bot-rassylki`, …) — русское имя вкладки
живёт только в `_tab.txt`, скрипты берут его оттуда. **Имя папки менять
безопасно, `_tab.txt` — нет.**

## Статусы ведёт ассистент сам
План → написан → опубликован. Обновлять при каждой смене состояния, у
опубликованных дописывать `ссылка:`. Посты прошедших дат в статусе «написан» —
уточнять у продюсера. Свод — `python3 skripty/plan.py`.

## Технические лимиты
Подпись к видео в Telegram — 1024 знака, обычный пост — 4096.

## Google-таблица
Таблица «Виола // Рабочее пространство» — витрина, источник правды всё равно
репозиторий. Синхронизация **односторонняя: репозиторий → таблица**; скрипт
пишет только в колонки «Тема / идея» и «Текст поста» и только в существующие
строки по дате — разметку, формулы и объединения не трогает, остальное правим в
таблице руками.

Перед записью — **всегда сухой прогон** (`python3 skripty/sheets_sync.py`),
показать продюсеру, потом `--apply`. Ключ сервис-аккаунта и настройка —
`kontent/kp/README.md`, `skripty/README.md`; нет ключа — попросить продюсера
прикрепить.
