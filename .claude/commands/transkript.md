Обработай новый транскрипт Виолы. Аргумент — **ссылка на видео** (YouTube и т.п.) **или путь к готовому файлу** транскрипта.

Порядок:
1. Получи транскрипт как сырьё в `korpus/`:
   - **Если дали ссылку на видео** — сними транскрипт плагином: `/watch <ссылка> --detail transcript` (только транскрипт с таймкодами, без кадров, дешевле всего). Сохрани полученный текст **как есть** в `korpus/` с очередным номером (`03-slug.txt`, `04-…` и т.д.).
     - Требует `ffmpeg` + `yt-dlp`: на Mac первый запуск поставит их сам (согласись на установку).
     - В облаке (Claude Code на вебе) эта ветка не сработает — нет `ffmpeg` и YouTube банит IP дата-центра. Поэтому ссылки гоняем **на локальной машине**.
   - **Если дали путь к файлу** — просто положи файл в `korpus/` с очередным номером.
   - `korpus/` — сырьё: ничего не редактируй, не чисти, не сокращай.
2. Расставь переносы строк: `python3 skripty/perenos.py korpus/<файл> --primenit`. Это не редактирование — меняются только пробельные символы, скрипт сам сверяет текст до и после и отказывается писать при расхождении. Без этого шага транскрипт часто остаётся одним абзацем на весь файл, и тогда любой `grep` по нему возвращает файл целиком (десятки тысяч токенов за один поиск).
3. Запусти `python3 skripty/razbor.py korpus/<файл>` и покажи, что нового относительно базы: метрики регистра (сырьё или отредактированная запись), новые темы, кандидаты-определения/техники, новые образы.
4. Предложи конкретные добавления в файлы базы. По каждому добавлению укажи:
   - в какой файл (`kanon-viny.md` / `golos-viola.md` / `tehniki-viola.md` / ...);
   - в какой раздел;
   - с какой меткой (`[Д]` дословно, `[П]` пересказ);
   - точную формулировку.
5. Ничего не записывай в базу без подтверждения продюсера. Сначала показать — потом, по команде, внести.
6. Файл, добавленный в `korpus/`, — закоммить и запушить (корпус тоже часть репозитория).

Если аргумента нет — спроси ссылку или путь.
