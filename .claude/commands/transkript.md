Обработай новый транскрипт Виолы.

Порядок:
1. Положи файл транскрипта в `korpus/` (имя с очередным номером: `03-...txt` и т.д.). korpus — это сырьё, ничего в нём не редактируй.
2. Запусти `python3 skripty/razbor.py korpus/<файл>` и покажи, что нового относительно базы: метрики регистра, новые темы, кандидаты-определения/техники, новые образы.
3. Предложи конкретные добавления в файлы базы. По каждому добавлению укажи:
   - в какой файл (`kanon-viny.md` / `golos-viola.md` / `tehniki-viola.md` / ...);
   - в какой раздел;
   - с какой меткой (`[Д]` дословно, `[П]` пересказ);
   - точную формулировку.
4. Ничего не записывай в базу без подтверждения продюсера. Сначала показать — потом, по команде, внести.

Аргумент команды — путь к новому транскрипту. Если пути нет, спроси.
